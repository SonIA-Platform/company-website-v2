# Contexto del proyecto SonIA

SonIA es una herramienta para departamentos de recursos humanos y equipos de seleccion que agiliza procesos de contratacion de alto volumen. Combina la informacion de una oferta y los CVs, analiza el encaje semantico, ordena candidatos y muestra una shortlist con justificacion. Despues facilita el contacto proactivo y la recogida estructurada de informacion para continuar el proceso.

## Propuesta De Valor

- Menos tiempo dedicado a lectura y prefiltrado manual.
- Shortlists priorizadas y mas faciles de accionar.
- Razonamiento visible detras de cada match.
- Proceso mas coherente entre ofertas, recruiters y ubicaciones.
- Continuidad entre screening, contacto y seguimiento.

La web no debe vender “IA” como una abstraccion. Debe mostrar como se transforma un proceso concreto.

## Publico Principal

- Direccion o responsables de RRHH.
- Recruiters internos.
- Empresas de trabajo temporal y consultorias de seleccion.
- Organizaciones con posiciones operativas, recurrentes o masivas.
- Empresas que trabajan en Espana y LATAM.

## Flujo Conceptual

1. Se crea o importa una oferta.
2. Se cargan o conectan los CVs.
3. SonIA interpreta oferta y candidatos semanticamente.
4. Calcula y ordena el encaje.
5. Muestra shortlist, score y motivos.
6. El recruiter revisa y selecciona.
7. Se inicia el contacto.
8. Se recogen datos y se hace avanzar al candidato.

## Prioridades De La Web

- Hero que explique resultado y destinatario sin ambiguedad.
- Visualizacion simple del flujo.
- Beneficios operativos concretos.
- Representacion creible del producto.
- Explicacion de transparencia y control humano.
- CTA claro y repetido sin saturacion.
- Contenido facil de escanear.
