# Quality Gate - Web SonIA

Una tarea visual o funcional no esta acabada hasta revisar los puntos aplicables.

## Marca

- `SonIA` escrito correctamente.
- Tokens del Design System en uso.
- Purple como color estructural principal.
- Gold reservado para acentos importantes.
- Sin estetica generica de IA.

## Copy Y Veracidad

- Idioma correcto para la pagina.
- Titular orientado a resultado y destinatario.
- Texto directo y escaneable.
- Sin claims, clientes, testimonios, precios o metricas inventadas.
- Placeholders pendientes marcados claramente.

## Responsive Y Accesibilidad

- 360 px sin overflow horizontal.
- 768 px con jerarquia correcta.
- 1024 px sin espacios desproporcionados.
- 1440 px con ancho de contenido controlado.
- HTML semantico.
- Un `h1` principal.
- Orden de headings correcto.
- Foco visible.
- Alt text correcto o decorativo.
- Movimiento reducido respetado.

## Rendimiento Y SEO

- JavaScript de cliente minimo.
- Imagenes dimensionadas.
- Sin dependencias nuevas innecesarias.
- Titulo unico y meta description util.
- `lang` correcto.
- Contenido principal indexable sin JS.

## Validacion

- Build ejecutado.
- Type-check ejecutado si existe.
- Lint ejecutado si existe.
- Tests ejecutados si existen.
- Resumen final con archivos modificados y limitaciones.
